## Менеджер паролей pass

- Данные хранятся в файловой системе в виде каталогов и файлов
- Файлы шифруются GPG-ключом
- Структура базы задаётся именами файлов

``` bash
pass init <gpg-id>
pass git init
```

## Добавление пароля

``` bash
pass insert -m example.com/user
pass show example.com/user
```

## Управление файлами конфигурации

``` bash
chezmoi init
chezmoi add ~/.bashrc
chezmoi managed
chezmoi status
```

<img src="image/lab05-chezmoi.png" style="width:70.0%" />

## Использование chezmoi на нескольких машинах

- Исходные файлы хранятся в `~/.local/share/chezmoi`
- Каталог является git-репозиторием
- Развёртывание на новой машине — одной командой `chezmoi apply`
