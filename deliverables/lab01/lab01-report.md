# Цель работы

Приобретение практических навыков установки операционной системы на
виртуальную машину, настройки минимально необходимых для дальнейшей
работы сервисов.

# Задание

1.  Установить дистрибутив Fedora Sway на виртуальную машину VirtualBox.
2.  Выполнить первичную настройку системы: обновление, отключение
    SELinux, настройку раскладки клавиатуры, установку имени
    пользователя и имени хоста, установку программного обеспечения для
    подготовки документации.
3.  Установить дополнения гостевой операционной системы (VirtualBox
    Guest Additions).
4.  Проанализировать последовательность загрузки системы с помощью
    команды `dmesg` и получить следующие сведения:
    - версия ядра Linux;
    - частота процессора;
    - модель процессора;
    - объём доступной оперативной памяти;
    - тип обнаруженного гипервизора;
    - тип файловой системы корневого раздела;
    - последовательность монтирования файловых систем.

# Теоретическое введение

Виртуальная машина — это программная среда, которая эмулирует аппаратное
обеспечение компьютера и позволяет запускать на нём полноценную
операционную систему параллельно с основной. В данной работе
используется VirtualBox — свободная программа виртуализации,
поддерживающая широкий набор гостевых операционных систем.

В качестве гостевой системы выбран дистрибутив Fedora Sway — сборка
Fedora Linux с оконным менеджером Sway, использующим протокол Wayland.

Команда `dmesg` выводит сообщения ядра, накопленные в кольцевом буфере.
Анализ этих сообщений позволяет установить параметры оборудования и
последовательность инициализации подсистем при загрузке \[1\]. Работа с
командной строкой и потоковым выводом описана в \[2\].

## Первичная настройка

Имя хоста приведено в соответствие с учётной записью:

``` bash
sudo hostnamectl set-hostname vzhang
```

Выполнено обновление установленных пакетов:

``` bash
sudo dnf -y upgrade
```

Установлено программное обеспечение, необходимое для подготовки
документации (компилятор, интерпретатор Perl, заголовочные файлы ядра):

``` bash
sudo dnf -y install gcc make perl kernel-devel kernel-headers elfutils-libelf-devel
```

## Установка дополнений гостевой ОС

Дополнения гостевой ОС устанавливались с образа
`VBoxGuestAdditions.iso`. Перед установкой потребовалось установить
пакеты сборки ядра, после чего запущен установщик:

``` bash
sudo mount /dev/sr0 /mnt/ga
sudo /mnt/ga/VBoxLinuxAdditions.run --nox11
```

Работоспособность дополнений проверена по загруженным модулям ядра и
состоянию службы (см.
<a href="#fig-ga" class="quarto-xref">Рисунок 2</a>):

``` bash
lsmod | grep -i vbox
systemctl is-active vboxservice
```

обеспечили работу общей папки между основной и гостевой системами.

С помощью команды `dmesg` получены требуемые сведения. Поиск по
сообщениям ядра выполнялся фильтром `grep`:

``` bash
sudo dmesg | grep -iE 'linux version|detected.*mhz|CPU0:|memory:|hypervisor'
findmnt -o TARGET,FSTYPE,SOURCE
```

# Контрольные вопросы

**1. Какую информацию содержит учётная запись пользователя?**

Учётная запись содержит имя пользователя, идентификатор пользователя
(UID), идентификатор основной группы (GID), список дополнительных групп,
домашний каталог, командную оболочку, а также параметры пароля в файле
`/etc/shadow`.

**2. Команды терминала и примеры их использования:**

Таблица 3: Основные команды терминала

| Назначение | Команда |

| Перемещение по файловой системе | `cd /etc`, `cd ..` |

**3. Что такое файловая система? Приведите примеры.**

Файловая система определяет способ организации, хранения и именования
данных на носителе. Примеры: ext4 — журналируемая файловая система с
поддержкой больших томов; XFS — высокопроизводительная журналируемая
файловая система; btrfs — файловая система с поддержкой подтомов, сжатия
и снапшотов; NTFS — основная файловая система Windows; exFAT — файловая
система для сменных носителей.

**4. Как посмотреть, какие файловые системы подмонтированы?**

Команды `mount`, `findmnt` или `df -hT` выводят список смонтированных
файловых систем, точки монтирования и их типы.

**5. Как удалить зависший процесс?**

Сначала определяется идентификатор процесса командой
`ps aux | grep имя_процесса`, затем процесс завершается командой
`kill PID`. Если процесс не реагирует на сигнал `SIGTERM`, применяется
`kill -9 PID`.

# Выводы

В ходе лабораторной работы установлена операционная система Fedora Sway
на виртуальную машину VirtualBox, выполнена первичная настройка системы,
установлены дополнения гостевой операционной системы. С помощью команды
`dmesg` получены сведения о версии ядра, процессоре, объёме оперативной
памяти, типе гипервизора и файловой системе корневого раздела, а также
восстановлена последовательность монтирования файловых систем.
Поставленные задачи выполнены в полном объёме.
