## Первичная настройка

- Имя хоста: `hostnamectl set-hostname vzhang`
- Обновление системы: `sudo dnf -y upgrade`
- Пакеты для сборки и документации:

``` bash
sudo dnf -y install gcc make perl kernel-devel kernel-headers elfutils-libelf-devel
```

## Дополнения гостевой ОС

- Монтирование образа и установка:

``` bash
sudo mount /dev/sr0 /mnt/ga
sudo /mnt/ga/VBoxLinuxAdditions.run --nox11
```

- Проверка: `lsmod | grep -i vbox`, `systemctl is-active vboxservice`
