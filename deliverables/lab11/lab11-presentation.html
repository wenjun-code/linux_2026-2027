Термины Emacs

  • Буфер — объект, содержащий текст
  • Фрейм — окно в обычном понимании
  • Окно — область фрейма, показывающая буфер
  • Область вывода — строки сообщений внизу
  • Минибуфер — ввод дополнительной информации
  • Точка вставки — позиция курсора в буфере

Префиксные клавиши

  • C- — Ctrl, M- — Meta/Alt/Esc, S- — Shift
  • C-x — префикс основных команд
  • C-c — префикс функций режима
  • M-x — выполнение команды по имени
  • F10 — доступ к меню

Буферы и окна

  • C-x C-b — список буферов
  • C-x b — переключение буфера
  • C-x o — переход в другое окно
  • C-x 0 — закрыть окно
  • C-x 3 — разделить по вертикали
  • C-x 2 — разделить по горизонтали

Четыре окна

Фрейм, разделённый на четыре окна

  • C-x 3, затем C-x 2 в каждом окне
  • В каждом окне свой буфер и текст
  • Строка состояния: имя буфера, режим, позиция

Поиск и замена

Инкрементальный поиск по шаблону HELLO

  • C-s — инкрементальный поиск, C-s — следующее вхождение
  • C-g — выход из режима поиска
  • M-% — поиск с заменой, ! — заменить все
  • M-s o — обзор всех вхождений в отдельном буфере
