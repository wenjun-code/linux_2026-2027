# Теоретическое введение

`Emacs` — мощный экранный редактор текста, написанный на языке высокого
уровня Elisp. Его основные термины приведены ниже \[1\]:

- **буфер** — объект, представляющий какой-либо текст (содержимое файла,
  результаты компиляции, подсказки); практически всё взаимодействие с
  пользователем происходит посредством буферов;
- **фрейм** — окно в обычном понимании, содержит область вывода и одно
  или несколько окон Emacs;
- **окно** — прямоугольная область фрейма, отображающая один из буферов;
  каждое окно имеет строку состояния (имя буфера, основной режим,
  признак изменения, позиция курсора);
- **область вывода** — одна или несколько строк внизу фрейма для
  сообщений и запросов;
- **минибуфер** — используется для ввода дополнительной информации,
  отображается в области вывода;
- **точка вставки** — место вставки (удаления) данных в буфере;
- **режим** — пакет расширений, изменяющий поведение буфера
  (Fundamental, Text, Lisp, C, Shell-script и др.).

Запуск: `emacs` (или `emacs &` для фоновой работы). Префиксные клавиши:
`C-` (Ctrl), `M-` (Meta/Alt/Esc), `S-` (Shift); `C-x` — префикс основных
команд, `C-c` — префикс функций, зависящих от режима, `M-x` — выполнение
команды по имени, `F10` — доступ к меню.

## Редактирование текста комбинациями клавиш

Выполнены стандартные процедуры редактирования (каждое действие —
комбинацией клавиш):

- `C-k` — вырезание целой строки в список удалений (kill-ring);
- `C-y` — вставка вырезанной строки в конец файла;
- `C-space` — начало выделения области, `C-w` — вырезание, `M-w` —
  копирование, `C-y` — вставка области;
- `C-/` — отмена последнего действия.

Перемещение курсора проверено командами `C-a` (начало строки), `C-e`
(конец строки), `M-<` (начало буфера), `M->` (конец буфера). После
возврата в начало буфера и выполнения `C-k`, `C-y` содержимое файла
восстановлено.

## Режим поиска и замены

Инкрементальный поиск запущен командой `C-s`; набран шаблон `HELLO`, при
этом все вхождения подсвечены, а курсор последовательно переходит между
результатами при повторном нажатии `C-s` — см.
<a href="#fig-emacs-search" class="quarto-xref">рис. 3</a>. Выход из
режима поиска — `C-g`.

<div id="fig-emacs-search">

<img src="image/em-4.png" style="width:95.0%" />

Поиск с заменой выполнен комбинацией `M-%`: введён искомый текст, нажата
`Enter`, затем текст замены; после подсветки результатов нажата `!` для
подтверждения замены всех вхождений. Режим `M-s o` (`occur`) выводит в
отдельный буфер список строк, содержащих совпадения, что отличается от
инкрементального поиска: он не перемещает курсор по тексту, а формирует
обзор всех вхождений в отдельном буфере.

Итоговое содержимое файла `~/work/os/lab07/lab07.sh`:

``` bash
#!/bin/bash
HELL=Hello
function hello {
    LOCAL HELLO=World
    echo $HELLO
}
echo $HELLO
hello
```

# Ответы на контрольные вопросы

## 1. Кратко охарактеризуйте редактор emacs

Emacs — мощный расширяемый экранный текстовый редактор, написанный на
языке Elisp, ядро которого фактически является интерпретатором Lisp с
редактором как одним из приложений. Он поддерживает множество режимов
для разных языков и задач, подсветку синтаксиса, работу с буферами,
окнами и фреймами, встроенную справку и учебник, систему расширений
(пакеты), интеграцию с компиляторами, отладчиками, системами контроля
версий, почтой и другими инструментами. Запускается в графическом и
терминальном режимах.

## 2. Какие особенности могут сделать его сложным для новичка?

- непривычная терминология (буфер, фрейм, окно, точка вставки,
  kill-ring);
- управление преимущественно «слепыми» комбинациями клавиш (`C-x C-f`,
  `M-x`), а не меню и кнопками;
- большое число команд и режимов, перегруженность функциями;
- префиксные клавиши (`C-x`, `C-c`, `M-`), различающиеся в разных
  режимах;
- нестандартные для современных редакторов обозначения (`C-`, `M-`,
  `S-`);
- необходимость знать Elisp для глубокой настройки.

## 3. Что такое буфер и окно в терминологии emacs?

**Буфер** — объект, содержащий текст: содержимое файла, вывод команды,
список буферов, справку и т. п. Буфер может не быть связан с файлом; в
нём выполняются все изменения, а запись в файл — отдельная операция
(`C-x C-s`). **Окно** — прямоугольная область фрейма, через которую
отображается один из буферов; один и тот же буфер может показываться в
нескольких окнах. Окно имеет строку состояния с именем буфера и режимом.

## 4. Можно ли открыть больше 10 буферов в одном окне?

Нет. В одном окне в каждый момент отображается **один** буфер. Буферов
можно открыть практически неограниченно много (ограничение — ресурсы
памяти), но переключаться между ними в одном окне можно последовательно
(`C-x b`, `C-x C-b`), а одновременно видеть разные буферы — только в
разных окнах фрейма.

## 5. Какие буферы создаются по умолчанию при запуске emacs?

При запуске создаются буфер `*scratch*` (для экспериментов, режим Lisp
Interaction), буфер `*Messages*` (журнал сообщений и ошибок), буфер
`*GNU Emacs*` (стартовый экран с приветствием и ссылками, если не
отключён), а также служебные буферы (`*Minibuf-0*`, `*Echo Area*` и
др.). При открытии файла создаётся буфер с его именем.

## 6. Какие клавиши нажать, чтобы ввести комбинацию C-c \| и C-c C-\|?

- `C-c |` — нажать и удерживать `Ctrl`, нажать `c`, отпустить, затем
  нажать `|` (обычно `Shift-Alt-|` на разных раскладках; в терминале —
  `C-c` затем `<`? Нет: символ `|` набирается как `Shift-\`).
- `C-c C-|` — нажать `C-c` (Ctrl+c), затем `Ctrl+Shift+\` (то есть
  `C-|`).

То есть сначала вводится префикс `C-c`, затем второй символ: для `|` —
обычный символ «вертикальная черта» (обычно `Shift-\`), для `C-|` — та
же клавиша с удержанием `Ctrl`.

## 7. Как поделить текущее окно на две части?

По горизонтали (одно над другим) — `C-x 2` (`split-window-below`); по
вертикали (одно рядом с другим) — `C-x 3` (`split-window-right`).
Переход между окнами — `C-x o`, закрытие текущего — `C-x 0`, закрытие
остальных — `C-x 1`.

## 8. В каком файле хранятся настройки редактора emacs?

В домашнем каталоге: файл `~/.emacs` (или `~/.emacs.el`), либо каталог
`~/.emacs.d/` с файлом `init.el`, либо (в новых версиях)
`~/.config/emacs/init.el`. Настройки записываются на языке Elisp; также
используется `~/.emacs.d/custom-file` для настроек, сохранённых через
`M-x customize`.

## 9. Какую функцию выполняет клавиша и можно ли её переназначить?

Любая клавиша в Emacs — это привязка (key binding) к команде Elisp;
выполнение команды можно переназначить на другую клавишу или вызвать по
имени через `M-x`. Переназначение выполняется функциями
`global-set-key`, `local-set-key`, `define-key` (например,
`(global-set-key (kbd "C-c h") 'help-command)`) и сохраняется в файле
инициализации. Существует также `M-x global-unset-key` для снятия
привязки. Клавиши — это просто имена событий, поэтому переназначить
можно практически любую.

## 10. Какой редактор удобнее: vi или emacs? Поясните.

Для кратких правок, работы по SSH и на маломощных системах удобнее
**vi**: он лёгкий, всегда установлен, режимы позволяют быстро
перемещаться и редактировать без мыши, команды компактны. Для длительной
работы с большими проектами, множеством файлов, интеграции с
компилятором, отладчиком и системой контроля версий удобнее **emacs**
благодаря буферам, окнам, режимам, встроенной справке и расширяемости. В
данной работе emacs показался удобнее для выполнения многошагового
задания (разделение окон, буферы, подсветка синтаксиса), тогда как vi —
быстрее для единичных правок.
