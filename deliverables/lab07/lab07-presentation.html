Переименование и перемещение

  • mv old new в пределах каталога — переименование записи каталога, данные не копируются
  • mv между разными ФС — копирование с последующим удалением источника
  • cp без опции -r не копирует каталог
mv ~/ski.plases/equipment ~/ski.plases/equiplist   # переименование
mv ~/newdir ~/ski.plases/plans                     # перемещение + переименование

Права доступа: восьмеричная запись

Задание Восьм. Символьная
drwxr--r-- … australia 744 rwx r-- r--
drwx--x--x … play 711 rwx --x --x
-r-xr--r-- … my_os 544 r-x r-- r--
-rw-rw-r-- … feathers 664 rw- rw- r--
  • r = 4, w = 2, x = 1; сумма цифры задаёт права группы
  • chmod 744 australia, chmod 711 play, chmod 544 my_os, chmod 664 feathers

Эксперименты с правами доступа

chmod u-r ~/feathers
cat ~/feathers        # Отказано в доступе
cp ~/feathers ~/f2    # Отказано в доступе
chmod u+r ~/feathers  # -rw-rw-r--

chmod u-x ~/play
cd ~/play             # Отказано в доступе
chmod u+x ~/play      # drwx--x--x

Смысл битов для каталога

  • r — просмотр списка имён в каталоге
  • w — создание и удаление файлов в каталоге
  • x — доступ к записям каталога, возможность сделать его текущим
  • Без x каталог нельзя открыть и обойти, даже если список имён читается
  • Владелец файла не может обойти установленные права (в отличие от root)

Команды обслуживания файловой системы

Команда Назначение Пример
mount монтирование и просмотр ФС mount /dev/sdb1 /mnt/data
fsck проверка и восстановление ФС fsck /dev/sda2
mkfs создание файловой системы mkfs -t ext4 /dev/sdb1
kill сигнал процессу kill -9 1234
  • fsck применяют к размонтированной ФС
  • mount -a монтирует всё из /etc/fstab
