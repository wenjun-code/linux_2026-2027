# Цель работы

Познакомиться с операционной системой Linux. Получить практические
навыки работы с редактором `vi`, установленным по умолчанию практически
во всех дистрибутивах.

# Задание

В соответствии с п. 8.3 методических указаний необходимо выполнить два
задания.

**Задание 1. Создание нового файла с использованием vi:**

1.  Создать каталог с именем `~/work/os/lab06`.
2.  Перейти во вновь созданный каталог.
3.  Вызвать `vi` и создать файл `hello.sh`.
4.  Нажать клавишу `i` и ввести текст скрипта (переменные `HELL`,

6.  Нажать `:` для перехода в режим последней строки.
7.  Набрать `wq` и нажать `Enter` для сохранения и выхода.
8.  Сделать файл исполняемым (`chmod +x hello.sh`).

**Задание 2. Редактирование существующего файла:**

1.  Вызвать `vi` на редактирование файла `~/work/os/lab06/hello.sh`.
2.  Установить курсор в конец слова `HELL` второй строки.
3.  Перейти в режим вставки и заменить на `HELLO`, нажать `Esc`.
4.  Установить курсор на четвёртую строку и стереть слово `LOCAL`.
5.  В режиме вставки набрать `local`, нажать `Esc`.
6.  Установить курсор на последней строке, вставить после неё строку
    `echo $HELLO`.
7.  Нажать `Esc`.
8.  Удалить последнюю строку.
9.  Ввести `u` для отмены последней команды.
10. Записать изменения и выйти из `vi` (`:wq`).

# Теоретическое введение

`vi` (Visual display editor) — интерактивный экранный текстовый
редактор, имеющий три режима работы \[1\]:

- **командный режим** — ввод команд редактирования и навигации по файлу
  (режим по умолчанию после запуска и после нажатия `Esc`);
- **режим вставки** — ввод содержимого файла (вход по `i`, `a`, `o` и
  др.);
- **режим последней (командной) строки** — запись изменений и выход из
  редактора (вход по `:`, `:`, `/`, `?`).

Вызов редактора: `vi <имя_файла>`; если файла нет, он создаётся. Выход с
сохранением — `:wq`, без сохранения — `:q!`.

Основные группы команд приведены в
<a href="#tbl-vi-cmds" class="quarto-xref">табл. 1</a>.

<div id="tbl-vi-cmds">

| Группа | Команды |
|----|----|
| Управление курсором | `h` ←, `l` →, `k` ↑, `j` ↓; `Space`/`Backspace` |
| Позиционирование | `0` — начало строки, `$` — конец строки, `G` — конец файла, `nG` — строка `n` |
| Перемещение по файлу | `Ctrl-d`/`Ctrl-u` — полэкрана, `Ctrl-f`/`Ctrl-b` — страница |
| Перемещение по словам | `w`/`W` — слово вперёд, `b`/`B` — назад, `nw`/`nb` — `n` слов |
| Вставка текста | `a` — после курсора, `A` — в конец строки, `i` — перед курсором, `I` — в начало, `o`/`O` — строка ниже/выше |
| Удаление | `x` — символ, `dw` — слово, `d$` — до конца строки, `d0` — до начала, `dd` — строка, `ndd` — `n` строк |
| Отмена/повтор | `u` — отменить, `.` — повторить |
| Копирование в буфер | `Y` — строка, `nY` — `n` строк, `yw` — слово |
| Вставка из буфера | `p` — после курсора, `P` — перед курсором |
| Замена | `cw` — слово, `nсw` — `n` слов, `c$` — до конца строки, `r`, `R` |
| Поиск | `/текст` — вперёд, `?текст` — назад |

</div>

В режиме последней строки доступны команды работы со строками и файлами:
`:n,m d` (удалить строки), `:i,j m k` (переместить), `:i,j t k`
(копировать), `:i,j w файл` (записать диапазон в файл), а также `:w`,
`:w файл`, `:wq`, `:q`, `:q!`, `:e!`. Опции задаются командой `set`:
`:set all`, `:set nu`, `:set list`, `:set ic`.

# Ответы на контрольные вопросы

## 1. Краткая характеристика режимов работы редактора vi

- **Командный режим** — основной режим, в который редактор попадает при
  запуске и после нажатия `Esc`. Клавиши интерпретируются как команды
  перемещения курсора, удаления, копирования, замены, поиска; текст не
  вводится.
- **Режим вставки** — предназначен для ввода содержимого файла; вход по
  `i`, `a`, `I`, `A`, `o`, `O`; выход по `Esc`.
- **Режим последней (командной) строки** — предназначен для записи
  файла, выхода, выполнения команд над строками и настройки опций; вход
  по `:`, `/`, `?`; команда выполняется по `Enter`, возврат в командный
  режим — `Esc`.
- Дополнительно различают **режим замены** (`R`) — вводимые символы
  замещают существующие.

## 2. Как выйти из редактора, не сохраняя изменения?

Перейти в командный режим (`Esc`), набрать `:` и команду `q!` (или `q`,
если изменений нет), нажать `Enter`. Команда `:q!` завершает работу без
записи изменений. Альтернативно — `ZQ` в командном режиме.

## 3. Команды позиционирования

- `0` (ноль) — переход в начало строки;
- `$` — переход в конец строки;
- `G` — переход в конец файла;
- `nG` — переход на строку с номером `n`;
- `gg` (или `1G`) — переход в начало файла;
- `w`/`b` — на слово вперёд/назад;
- `Ctrl-d`/`Ctrl-u` — на полэкрана вперёд/назад;
- `Ctrl-f`/`Ctrl-b` — на страницу вперёд/назад.

## 4. Что для редактора vi является словом?

Слово — последовательность символов, ограниченная разделителями. При
использовании **строчных** команд `w`/`b` разделителями считаются
пробелы, табуляции, переводы строки, а также любые знаки пунктуации; при
использовании **прописных** `W`/`B` разделителями являются только
пробел, табуляция и возврат каретки, поэтому знаки пунктуации считаются
частью слова.

## 5. Как перейти в начало (конец) файла из любого места?

В командном режиме: в начало файла — `gg` или `1G`; в конец файла — `G`.
Также можно использовать поиск: `:1` — переход на первую строку, `:$` —
на последнюю.

## 6. Основные группы команд редактирования

- **вставка текста**: `a`, `A`, `i`, `I`, `o`, `O`, `n i`;
- **удаление текста**: `x`, `dw`, `d$`, `d0`, `dd`, `ndd`;
- **отмена и повтор**: `u`, `.`;
- **копирование в буфер**: `Y`, `nY`, `yw`;
- **вставка из буфера**: `p`, `P`;
- **замена текста**: `cw`, `ncw`, `c$`, `r`, `R`;
- **поиск текста**: `/текст`, `?текст`.

## 7. Необходимо заполнить строку символами \$. Каковы действия?

Войти в режим вставки (`i` или `a`), набрать `$` нужное число раз,
нажать `Esc`. Для повторяющегося ввода удобно использовать счётчик:
`n i` — вставляет набранный текст `n` раз (например, `70i$` + `Esc`
заполнит 70 символами `$`). Другой способ — команда `:normal` или замена
регулярным выражением `:s/^/$/` (вставка `$` в начало) либо `:s/$/$/`. В
командном режиме символ `$` сам по себе означает «переход в конец
строки», поэтому его нельзя набрать без перехода в режим вставки.

## 8. Как отменить некорректное действие, связанное с процессом редактирования?

В командном режиме нажать `u` — отмена последнего изменения; повторное
нажатие `u` отменяет предыдущие изменения (многоуровневая отмена в vim).
Повторить последнее изменение позволяет `.`. Вернуться к состоянию файла
на диске, отменив все изменения с момента последней записи, — команда
`:e!`.

## 9. Основные группы команд режима последней строки

- **копирование и перемещение строк**: `:n,m d` — удалить строки
  `n`–`m`; `:i,j m k` — переместить строки `i`–`j` после строки `k`;
  `:i,j t k` — копировать строки `i`–`j` в позицию `k`; `:i,j w файл` —
  записать диапазон в файл;
- **запись и выход**: `:w`, `:w файл`, `:w! файл`, `:wq`, `:q`, `:q!`,
  `:e!`;
- **опции**: `:set all`, `:set nu`, `:set list`, `:set ic`;
- **поиск и замена**: `:s/шаблон/замена/g`, `:%s/…/…/g`;
- **переходы**: `:n` — на строку `n`, `:$` — в конец файла.

## 10. Как определить, не перемещая курсора, позицию, в которой заканчивается строка?

Набрать `$` — курсор перейдёт в конец строки (это перемещение, но
однозначно определяет позицию). Не перемещая курсор, информацию о
позиции даёт команда `Ctrl-g` (в vim выводит имя файла, номер строки,
общее число строк, процент), а также `:set list` (показывает символы
конца строки `$`), `:set ruler` (координаты курсора в правом нижнем
углу). В классическом `vi` — `Ctrl-g` и `:set ruler`.

## 11. Анализ опций редактора vi

Полный список опций выводит команда `:set all` — в vim это несколько
сотен опций (в классическом `vi` — несколько десятков). Опции делятся на
логические (`nu`, `list`, `ic`, `ai`, `wrap`) и числовые (`tabstop`,
`shiftwidth`, `report`). Назначение каждой опции описано в
`man vi`/`:help <опция>`; отключение логической опции выполняется
добавлением префикса `no` (например, `:set nonu`).

## 12. Как определить режим работы редактора vi?

- в **режиме вставки** внизу экрана отображается `-- INSERT --` (в vim
  также `-- ВСТАВКА --`), в режиме замены — `-- REPLACE --`;
- в **режиме последней строки** внизу виден приглашающий символ `:` (или
  `/`, `?`);
- в **командном режиме** индикации нет, возврат в него — по `Esc`; при
  нажатии клавиш текст не вводится, а выполняются команды. Дополнительно
  режим виден по поведению: вставка изменяет текст, командный режим —
  перемещает курсор или выполняет операции.

## 13. Граф взаимосвязи режимов работы редактора vi

            запуск vi
                │
                ▼
       ┌──► командный режим ◄──────── Esc ────────┐
       │        │      │                          │
       │   i,a,o   :,/,?                          │
       │        ▼      ▼                          │
       │  режим вставки  режим последней строки ──┘
       │        │                 │
       └── Esc ─┘            Enter (команда
                              выполняется),
                             Esc — возврат

Из командного режима в режим вставки переход по `i`, `a`, `o`, `I`, `A`,
`O`, `R`; обратно — по `Esc`. В режим последней строки — по `:`, `/`,
`?`; команда выполняется по `Enter`, возврат в командный режим — по
`Esc`. Выход из редактора возможен только из режима последней строки
(`:wq`, `:q!`).
