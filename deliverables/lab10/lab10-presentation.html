Задание

Задание 1. Создать файл hello.sh в каталоге ~/work/os/lab06 с помощью vi:

#!/bin/bash
HELL=Hello
function hello {
LOCAL HELLO=World
echo $HELLO
}
echo $HELLO
hello

Задание 2. Отредактировать файл: заменить HELL на HELLO, LOCAL на local, вставить строку echo $HELLO, удалить последнюю строку, отменить удаление, сохранить и выйти.

Выполнение работы

Режимы редактора vi

  • Командный — навигация и команды редактирования (после запуска и по Esc)
  • Вставки — ввод текста (i, a, o, I, A, O)
  • Последней строки — запись, выход, опции (:, /, ?)

Задание 1: создание hello.sh

mkdir -p ~/work/os/lab06
cd ~/work/os/lab06
vi hello.sh
  • i — переход в режим вставки
  • Набран текст скрипта
  • Esc — возврат в командный режим
  • :wq + Enter — запись и выход
  • chmod +x hello.sh — файл стал исполняемым

Режим вставки: ввод текста hello.sh

Задание 2: редактирование файла

Шаг Команда Действие
1 2G переход на вторую строку
2 cw + HELLO замена HELL на HELLO
3 4G, dw удаление слова LOCAL
4 i + local вставка local
5 G, o вставка строки ниже
6 echo $HELLO текст новой строки
7 dd удаление последней строки
8 u отмена удаления
9 :wq запись и выход

Файл hello.sh после редактирования (:set nu)

Результат выполнения

Hello

  • local HELLO=World внутри функции — World
