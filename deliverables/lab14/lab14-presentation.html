Выполнение работы

1. Упрощённый семафор

while ! mkdir "$LOCK" 2>/dev/null; do
  echo "[$$] ресурс занят, жду $T1 с..."
  sleep "$T1"
done
echo "[$$] РЕСУРС ЗАХВАЧЕН, использую $T2 с"
sleep "$T2"
rmdir "$LOCK"
  • mkdir — атомарная операция, служит замком
  • $$ — PID процесса, различает участников
  • Поддерживается 3 и более процесса
  • Вывод можно перенаправить в другой терминал: > /dev/ttyN

Три процесса и упрощённый семафор

2. Реализация команды man

for f in "$DIR/$CMD".1 "$DIR/$CMD".1.gz "$DIR/$CMD".1.xz; do
  [ -f "$f" ] || continue
  zcat "$f" | GROFF_NO_SGR=1 groff -man -Tutf8 | col -b
  exit 0
done
echo "Справка не найдена" >&2
exit 1
  • Страницы в /usr/share/man/man1 хранятся сжатыми (.gz)
  • zcat + groff -man -Tutf8 + col -b — форматирование
  • Отсутствующая команда → сообщение и код возврата 1

3. Генератор случайных букв

ALPH="abcdefghijklmnopqrstuvwxyz"
for ((i=0; i<LEN; i++)); do
  s+="${ALPH:RANDOM%26:1}"
done
  • $RANDOM — 0…32767
  • % 26 — индекс 0…25
  • ${ALPH:index:1} — выбор буквы
  • Пример: sbebqbqthgwf
