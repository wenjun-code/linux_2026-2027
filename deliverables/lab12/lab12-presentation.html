Теоретические сведения

Командные оболочки

  • sh — оболочка Борна, базовый набор
  • csh — C-подобный синтаксис, история команд
  • ksh — оболочка Корна
  • bash — Bourne Again Shell, свойства csh и ksh

Переменные и специальные параметры

Переменная Назначение
$0 имя запущенного файла
$1…${10} позиционные параметры
$# число параметров
$*, $@ все параметры
$? код возврата
$$ PID оболочки
$! PID фонового процесса

Выполнение работы

1. Резервная копия самого себя

#!/bin/bash
DEST="$HOME/backup"
mkdir -p "$DEST"
STAMP=$(date +%Y%m%d-%H%M%S)
tar -czf "$DEST/$(basename "$0").$STAMP.tar.gz" "$0"
  • $0 — путь к самому скрипту
  • tar -czf — создание архива с gzip-сжатием
  • архив проверен: tar -tzf ~/backup/*.tar.gz

Работа скриптов backup.sh и args.sh

2. Обработка произвольного числа аргументов

for a in "$@"; do echo "аргумент: $a"; done
shift 2
echo "осталось: $#"
  • "$@" корректно перебирает любое число аргументов
  • $# — количество, shift n — сдвиг списка

3. Аналог команды ls

for f in "$DIR"/* "$DIR"/.[!.]*; do
  [ -e "$f" ] || continue
  printf '%-48s %s\n' "$(basename "$f")" "$(stat -c '%A %U:%G %6s %y' "$f")"
done
  • Не используются ls и dir
  • Права доступа — через stat %A
  • Выводятся и скрытые файлы (.[!.]*)

4. Подсчёт файлов заданного формата

EXT="${1:?укажите формат}"
DIR="${2:-.}"
n=0
for f in "$DIR"/*."$EXT"; do [ -f "$f" ] && n=$((n+1)); done
echo "Файлов .$EXT в $DIR: $n"
  • ${1:?} — обязательный аргумент с сообщением
  • ${2:-.} — значение по умолчанию
  • результат: .sh — 4 файла, .png — 3 файла
